# dsa-cpp

Data Structures & Algorithms practice in C++, using STL.

Successor to [dsa-in-c] — DSA practice moved from C to C++ 
to use STL containers/algorithms, which better reflects real 
interview and industry expectations.

## Structure
- Pattern-based approach following NeetCode 150 categories
- `REDO.md` — log of problems that took >25 min or failed, 
  for spaced repetition (redo at day+3, day+10)
- Pattern Cards — template code shapes per pattern (not solved 
  problems), for quick pattern recall

## Progress
Phase 0: STL crash course (vectors, maps/sets, stacks/queues) — in progress
Phase 1: Pattern grind (Arrays & Hashing → Two Pointers → ... )
Phase 2: Advanced patterns + DP (with ML alternation resumed)

Target: ~150 problems by Feb 2027
